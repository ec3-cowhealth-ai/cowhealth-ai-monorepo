# Documentation Map

This repository uses three documentation layers:

- Source of truth: docs that should match the current codebase.
- Working docs: current reviews, handoffs, and reports used during execution.
- Historical docs: plans, audits, and old implementation notes kept for context only.

If a document conflicts with the code, trust the code and update the source-of-truth doc.
